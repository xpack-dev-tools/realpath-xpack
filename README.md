# The xPack GNU realpath

A standalone, cross-platform (macOS, GNU/Linux) binary
distribution of GNU realpath,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack-dev-tools.github.io/realpath-xpack/).

## Project source

The source code of the current release is available on
GitHub as [xpack-dev-tools/realpath-xpack](https://github.com/xpack-dev-tools/realpath-xpack),
the [v9.8.0-1.1](https://github.com/xpack-dev-tools/realpath-xpack/tree/v9.8.0-1.1) tree.
